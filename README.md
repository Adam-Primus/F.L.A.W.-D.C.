# F.L.A.W.-D.C.
## *Follows Line Autonomous Weak - Dumb Car*
**F.L.A.W.-D.C** is a simple line follower autonomus toy car that is controlled by a Microcontroller [DOIT ESP32 Devkit v1] and runs on electricity.

## Why make this ?

I am a beginner and this is my first project where I control a motro using an esp32 so this
will be a newer esperiebce to me and additionally I still have a large a large part on coding firmware so this project is a stepping stone for my future projects.
